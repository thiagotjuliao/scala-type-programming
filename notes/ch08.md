# Chapter 08 — `inline` & `scala.compiletime`

My notes on what each exercise taught. Reconstructed on 2026-10-13. This
chapter was solved without a tutoring session, so everything here comes from
the answer key's scaladoc.

## Exercise 01 — a port checked while compiling

| piece | idea |
| --- | --- |
| `constValue[N]` + `inline if` | a literal type read as a constant, decided during expansion |
| `error(...)` in the discarded branch | only the branch reached by the expansion stops the compilation |
| `Port[Int]` | `constValue` fails on its own: *"Int is not a constant type"* |

## Exercise 02 — a default value for every type that has one

| piece | idea |
| --- | --- |
| `inline erasedValue[T] match` | a match on a type, with no value; only the matching case is kept |
| `case _: (a, b)` | binds the component types and recurses |
| casts in the body | the body is checked at the definition, where `T` is unknown |

## Exercise 03 — chapter 07's `add`, with a value

| piece | idea |
| --- | --- |
| `inline match` on the arguments' static types | no runtime test, so erasure never matters |
| `transparent inline` | the call gets the type of its expansion, not the declared `Any` |

## Exercise 04 — use an instance if there is one

| piece | idea |
| --- | --- |
| `summonFrom` | a match whose cases are instance searches, tried in order at the call site |
| last case `error(...)` | a fallback that fails with my message, which chapter 06's ranking could not express |
| plain `summon` in the body | resolved at the definition, for an unknown `A` |
