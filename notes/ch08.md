# Capítulo 08 — `inline` & `scala.compiletime`

Minhas notas sobre o que cada exercício ensinou. Reconstruídas em 2026-10-13.
Este capítulo foi resolvido sem sessão de tutoria, então tudo aqui vem do
Scaladoc do gabarito.

## Exercício 01 — uma porta verificada na compilação

| peça | ideia |
| --- | --- |
| `constValue[N]` + `inline if` | um tipo literal lido como constante, decidido durante a expansão |
| `error(...)` no ramo descartado | só o ramo alcançado pela expansão interrompe a compilação |
| `Port[Int]` | o próprio `constValue` falha: *"Int is not a constant type"* |

## Exercício 02 — um valor default para todo tipo que tem um

| peça | ideia |
| --- | --- |
| `inline erasedValue[T] match` | um match sobre um tipo, sem valor; só o caso que casa é mantido |
| `case _: (a, b)` | liga os tipos dos componentes e recorre |
| casts no corpo | o corpo é checado na definição, onde `T` é desconhecido |

## Exercício 03 — o `add` do capítulo 07, com um valor

| peça | ideia |
| --- | --- |
| `inline match` sobre os tipos estáticos dos argumentos | sem teste em runtime, então o erasure não importa |
| `transparent inline` | a chamada recebe o tipo da expansão, não o `Any` declarado |

## Exercício 04 — usar uma instância se houver uma

| peça | ideia |
| --- | --- |
| `summonFrom` | um match cujos casos são buscas de instância, tentadas em ordem no ponto da chamada |
| último caso `error(...)` | uma alternativa que falha com a minha mensagem, o que o ranking do capítulo 06 não conseguia expressar |
| `summon` simples no corpo | resolvido na definição, para um `A` desconhecido |
