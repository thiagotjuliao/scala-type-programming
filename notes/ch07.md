# Capítulo 07 — Match types

Minhas notas sobre o que cada exercício ensinou. Reconstruídas em 2026-10-13 a
partir da sessão de 2026-09-25 (exercícios 01, 03 e 04) e, para o exercício
02, do Scaladoc do gabarito.

## Exercício 01 — tirar uma camada de um tipo

| peça | ideia |
| --- | --- |
| `case Option[a] => a` | o teste é por subtipagem, então `Some` e `Right` não precisam de caso próprio |
| `Either[?, a]` | um curinga onde o binder ficaria sem uso |
| `case _ => X` por último | em primeiro, casaria com tudo; por último, só é alcançado depois que os outros são provados disjuntos |

**Onde travei:** nada no código — o teste só falhava no VS Code. O Bloop não
roda o carimbo dos snippets, então a spec era julgada contra o stub antigo.
Resolvido usando o sbt como build server do Metals.

## Exercício 02 — tirar todas as camadas de um tipo *(do gabarito)*

| peça | ideia |
| --- | --- |
| `case Option[a] => Leaf[a]` | recorrer pelo próprio tipo, não pelo `Unwrap` do exercício 01 |
| o catch-all é o caso base | fora do seu domínio, um match type não falha, só nunca reduz |

## Exercício 03 — um tipo de resultado calculado a partir do argumento

| peça | ideia |
| --- | --- |
| um padrão tipado por caso, na mesma ordem | só um match de valores que espelha o match type deixa cada ramo ser checado contra o tipo reduzido |
| `s.headOption` | o "está vazio?" fica dentro do ramo, não em casos a mais |

**Onde travei:** escrevi seis padrões de valor e extratores (`""`, `Nil`,
`None`, `h :: _`...) — cada ramo passou a ser checado contra um `First[X]`
preso.

## Exercício 04 — unidades que se cancelam

| peça | ideia |
| --- | --- |
| `(U, V) match` | um par como scrutinee compara as duas unidades de uma vez |
| `c match { case b => a }` | dentro do resultado, `b` é o tipo que o padrão de fora ligou: é assim que se comparam dois tipos |
| um `case _` interno | escolhido um caso de fora, o catch-all de fora sai de jogo; o match interno precisa do seu próprio "senão" |

**Onde travei:** `speed * distance` ficava
`Meters match { case Seconds => Meters }` — o match interno não tinha
alternativa, e o compilador não volta atrás para tentar o próximo caso de fora.
