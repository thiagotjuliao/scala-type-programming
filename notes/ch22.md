## Exercise 01 — a schema builder

| piece | idea |
| --- | --- |
| `K <: String & Singleton` | without `Singleton`, `"age"` widens to `String`; match types test by subtyping, so the lookup stops at the first pair |
| `(key: K)` before the `using` | parameter lists are resolved left to right; evidence first means `K` is still only its bound |
| `(n *: v *: EmptyTuple) *: t` | a pair is `n *: v *: EmptyTuple`; without the `EmptyTuple`, `v` takes the pair's tail |
| `Contains` not built on `Lookup` | the builder's state is a tuple of keys, not of pairs; each match type walks the shape it gets |
| `case EmptyTuple => false` | without it the match type is stuck exactly at the empty tuple, where every builder starts |
| `value: Lookup[Schema, K]` | a wrong key gives `Nothing`, and no value has type `Nothing` |

**Learned (and added to chapter 07's pitfalls):** a match type whose
scrutinee is `Nothing` does not reduce.

## Exercise 02 — `build` only when complete

| piece | idea |
| --- | --- |
| `AllIn[Required, S]`, in that order | `R` is what must be contained; inverted, the test without `age` passed by coincidence |
| `@implicitNotFound` on my own trait | on the `=:=` inside a `using`, the text only became part of the printed type |
| `given ... => (AllIn[...] =:= true) => Completed[S]` | before the last arrow is the condition, after it what the given provides |
| `new Completed[S] {}` | a trait has no constructor: an anonymous class, or a `class` |

## Exercise 03 — a connection that follows its protocol

| piece | idea |
| --- | --- |
| `send(message: Tuple.Head[Left])` | the message's type is computed from the state |
| `Conn[Tuple.Append[Sent, Tuple.Head[Left]], Tuple.Tail[Left]]` | type and value grow together; `sent :* message` is the value whose type is `Append` |
| a message after the last | `Tuple.Head[EmptyTuple]` is stuck, and no value has a stuck type |
| `close(conn: Conn[P, EmptyTuple]): P` | the parameter's type is the rule; `sent` reduces to `P`, no cast |
| `Conn` inside `Server` | `server.Conn` and `other.Conn` differ even with the same `P` |
| `private[Server]` constructor | plain `private` would hide it from `connect()` too |

**Stuck on:** `.Head` is not type syntax — it is `Tuple.Head[Left]`. And I
first thought restricting `P` would separate the servers; it is the class's
path that does.
