# Chapter 12 — Macros: quotes & splices

My notes on what each exercise taught. Reconstructed on 2026-10-13 from the
sessions of 2026-10-02 (exercises 01–03) and 2026-10-04 (exercise 04).

## Exercise 01 — an expression, and what it was

| piece | idea |
| --- | --- |
| `valueOrAbort` does not fit | the macro runs while compiling; `x` has no value yet |
| `a.asTerm.pos.sourceCode` | an `Option[String]`; fall back to `a.show` for trees nobody typed |
| `Expr(text)` then `$text` in the quote | compute what is known now outside the quote (level 0), splice it in as code (level 1) |
| `$a` in the quote | the value is evaluated later, at runtime |

**Stuck on:** *"access to parameter x$2 from wrong staging level"* — I had
put `a.asTerm.pos...` inside the quote, asking the running program for the
compiler's positions.

## Exercise 02 — a regular expression checked while compiling

| piece | idea |
| --- | --- |
| no `ToExpr[Regex]` | lift the `String` and build the `Regex` at runtime with `.r` |
| `pattern.value` (an `Option`) | instead of `valueOrAbort`, so the error message is mine |
| `report.errorAndAbort(msg, pattern)` | the error points at the argument |

## Exercise 03 — the name of a field, not a string

| piece | idea |
| --- | --- |
| `Printer.TreeStructure` | print the tree to see the node shapes before writing patterns |
| unwrap `Inlined` and `Apply(_, Nil)` | wrappers; `String.length` is a Java method called with `()` |
| `Select(_, name)`, `Ident(name)` | the outermost `Select` is the last name written; a local is an `Ident` |
| `Apply` with arguments | an operation (`x + 2`), not a name: reject |

**Stuck on:** my first version returned `"+"` for `x + 2` and rejected a local
`p` — the spec passed by luck (`1 + 2` folds to `3`, and the spec's `person`
is a field).

## Exercise 04 — a case class, as the compiler sees it

| piece | idea |
| --- | --- |
| `TypeRepr.of[T].typeSymbol` | the class's declaration |
| `sym.flags.is(Flags.Case)` + guard `if ... then errorAndAbort` | `errorAndAbort` has type `Nothing`, a *subtype* of every type |
| `tpe.memberType(f)` | the field's type *within* `T`: `Wrap[Int]`'s `a` is `Int`, not `A` |
| `show(using Printer.TypeReprShortCode)` | short names, and type arguments kept (`List[Int]`, not `List`) |
| name from the type, not `sym.name` | `Id[User]` and `Id[Order]` stay distinct for a phantom parameter |
