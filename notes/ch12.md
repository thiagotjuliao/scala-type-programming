# Capítulo 12 — Macros: quotes & splices

Minhas notas sobre o que cada exercício ensinou. Reconstruídas em 2026-10-13 a
partir das sessões de 2026-10-02 (exercícios 01 a 03) e 2026-10-04 (exercício
04).

## Exercício 01 — uma expressão, e o que ela era

| peça | ideia |
| --- | --- |
| `valueOrAbort` não serve | a macro roda na compilação; `x` ainda não tem valor |
| `a.asTerm.pos.sourceCode` | um `Option[String]`; cair para `a.show` em árvores que ninguém digitou |
| `Expr(text)` e depois `$text` no quote | calcular fora do quote (nível 0) o que se sabe agora e emendar como código (nível 1) |
| `$a` no quote | o valor é avaliado depois, em runtime |

**Onde travei:** *"access to parameter x$2 from wrong staging level"* — eu
tinha posto `a.asTerm.pos...` dentro do quote, pedindo ao programa em execução
as posições do compilador.

## Exercício 02 — uma expressão regular verificada na compilação

| peça | ideia |
| --- | --- |
| não existe `ToExpr[Regex]` | levar a `String` e construir o `Regex` em runtime com `.r` |
| `pattern.value` (um `Option`) | no lugar de `valueOrAbort`, para a mensagem de erro ser minha |
| `report.errorAndAbort(msg, pattern)` | o erro aponta para o argumento |

## Exercício 03 — o nome de um campo, não uma string

| peça | ideia |
| --- | --- |
| `Printer.TreeStructure` | imprimir a árvore para ver as formas dos nós antes de escrever os padrões |
| descascar `Inlined` e `Apply(_, Nil)` | embrulhos; `String.length` é um método Java chamado com `()` |
| `Select(_, name)`, `Ident(name)` | o `Select` mais externo é o último nome escrito; uma variável local é um `Ident` |
| `Apply` com argumentos | uma operação (`x + 2`), não um nome: recusar |

**Onde travei:** a primeira versão devolvia `"+"` para `x + 2` e recusava um
`p` local — a spec passou por sorte (`1 + 2` vira `3` antes, e o `person` da
spec é um campo).

## Exercício 04 — uma case class, como o compilador a vê

| peça | ideia |
| --- | --- |
| `TypeRepr.of[T].typeSymbol` | a declaração da classe |
| `sym.flags.is(Flags.Case)` + guarda `if ... then errorAndAbort` | `errorAndAbort` tem tipo `Nothing`, *subtipo* de todos os tipos |
| `tpe.memberType(f)` | o tipo do campo *dentro de* `T`: o `a` de `Wrap[Int]` é `Int`, não `A` |
| `show(using Printer.TypeReprShortCode)` | nomes curtos, mantendo os argumentos de tipo (`List[Int]`, não `List`) |
| nome pelo tipo, não por `sym.name` | `Id[User]` e `Id[Order]` continuam distintos com um parâmetro phantom |
