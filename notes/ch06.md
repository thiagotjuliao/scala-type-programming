# Capítulo 06 — Type classes, givens & implicit search

Minhas notas sobre o que cada exercício ensinou. Reconstruídas em 2026-10-13 a
partir da sessão de 2026-09-25 (exercício 04) e, para os outros, do Scaladoc
do gabarito.

## Exercício 01 — um Show para tudo que é feito de partes mostráveis *(do gabarito)*

| peça | ideia |
| --- | --- |
| `[A: Show] => Show[List[A]]` | uma instância condicional: uma regra com premissa, encadeada pela busca |
| instâncias no companion | no escopo implícito de toda busca por `Show[...]`, sem import |
| `import X.*` | não traz givens; `import X.given` traz |

## Exercício 02 — uma ordenação encontrada em todo lugar, e outra sob pedido *(do gabarito)*

| peça | ideia |
| --- | --- |
| `Ordering.by(v => (major, minor, patch))` | reaproveitar a ordenação de tuplas da biblioteca em vez de comparar à mão |
| `NewestFirst` importado | o escopo léxico é buscado antes do implícito, então as duas instâncias nunca se encontram |

## Exercício 03 — duas regras se aplicam; dizer qual ganha *(do gabarito)*

| peça | ideia |

## Exercício 04 — um tipo de resultado calculado pela busca

| peça | ideia |
| --- | --- |
| `add(a, b)(using c: Add[A, B]): c.Out` | o tipo do resultado depende da instância que a busca escolheu |
| instâncias declaradas como `Aux[A, B, O]` | declarada como `Add[Int, Int]` simples, a instância esquece o seu `Out` |
| `given pair[A, B, C, D, O1, O2](using first: Aux[A, B, O1], second: Aux[C, D, O2]): Aux[(A, C), (B, D), (O1, O2)]` | as premissas fixam `O1` e `O2`; pares aninhados recorrem pela mesma regra |

**Onde travei:** o munit dizia *"Can't compare these two types:
given_Add_Int_Int.Out and Int"* — a instância tinha perdido o `Out` porque eu
a declarei como `Add`. Na regra de pares: `A` pareia com `B` e `C` com `D`
(lados opostos), não `A` com `C`.

**Aprendi no caminho:** um given condicional pode ser escrito com `using`
(`given nome[T](using ...): Resultado`) ou com a sintaxe de setas
(`given [T] => (s: Show[T]) => Resultado`); a de setas é a preferida desde o
Scala 3.6 (SIP-64).
