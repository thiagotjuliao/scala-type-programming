# Chapter 10 — `Mirror` & generic derivation

My notes on what each exercise taught. Reconstructed on 2026-10-13 from the
session of 2026-10-01, the first one done question by question.

## Exercise 01 — a type's name and its field names

| piece | idea |
| --- | --- |
| `using m: Mirror.Of[T]` | the mirror arrives with its refinement, so `m.MirroredLabel` *is* `"Person"` |
| `constValue` / `constValueTuple` | a literal type, or a tuple of them, read back as values |
| `val m = summonInline[...]` | the near miss: the `val` has the declared type, the members are abstract again |

**Learned:** with type members, think in types as long as possible and turn
into a value only at the end, and only what is a literal.

## Exercise 02 — `Show` for any case class

| piece | idea |
| --- | --- |
| field values | every case class is a `Product`; `productIterator` gives the values as `Any` |
| instances per field | inline recursion over `MirroredElemTypes` with `erasedValue` |
| find or derive | `summonFrom`: use a `Show[H]` if there is one, otherwise derive from `Mirror.ProductOf[H]` |
| the cast | safe because the order is guaranteed; it lives in `instances`, where the type is forgotten, and erasure makes it free |
| inline only what must be | the mirror is read during expansion; the runtime logic is an ordinary method |
| recursive types | `elems` by name, and a `lazy val` *outside* the lambda |

**Stuck on:** a `for` with three generators is a cartesian product, and an
`Iterator` can be read only once — `lazyZip` walks three lists side by side.
`Show` is invariant, not covariant: it *consumes* `A`, so the sound variance
would be `-A`. An ascription asks the compiler to prove a type; `asInstanceOf`
is a promise it does not check.

## Exercise 03 — every value of an enum

| piece | idea |
| --- | --- |
| `SumOf` | `MirroredElemTypes` are the cases, in declaration order |
| `ValueOf[T]` | goes from a singleton type to its one value; `constValue` covers literal types only |
| `error` | takes a string literal only — it runs while compiling and does not run `s"..."` |
| a pattern's `h` inside `summonFrom` | does not act as the concrete type; pass it to an `inline def` with its own type parameter |

**Also:** the warning *"New anonymous class definition will be duplicated at
each inline site"* — moved the `new Values[A]` into an ordinary method.

## Exercise 04 — a case class from its fields, and back

| piece | idea |
| --- | --- |
| `build[T](using m: Mirror.ProductOf[T])(fields: m.MirroredElemTypes)` | a type can only depend on an *earlier* parameter, so the `using` clause comes first |
| `(...)` skips `using` clauses | a plain argument list goes to the next ordinary list |
| `Tuple` extends `Product` | `fromProduct` needs no cast |
| `Tuple.fromProductTyped` with `T <: Product` | removes both casts in `fields` |
