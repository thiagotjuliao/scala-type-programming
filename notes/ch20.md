# Capítulo 20 — Validation

Minhas notas sobre o que cada exercício ensinou. Reconstruídas em 2026-10-13 a
partir da sessão de 2026-10-05 (exercício 04) e, para os outros, do Scaladoc
do gabarito.

## Exercício 01 — um valor ou os erros que o impediram *(do gabarito)*

| peça | ideia |
| --- | --- |
| `Validated[+E, +A]` | `Valid(42)` é um `Validated[Nothing, Int]`; a covariância o faz caber em qualquer tipo de erro |
| invariante ainda compilaria no lugar | a falha só aparece quando um resultado é guardado antes e usado depois |

## Exercício 02 — combinar dois resultados, guardando os erros dos dois *(do gabarito)*

| peça | ideia |
| --- | --- |
| instâncias de `Semigroup` no companion dele | o único companion do escopo implícito que este código controla |
| `map2[E: Semigroup]` | um tipo de erro que não combina (`Boolean`) vira erro de compilação |
| `e1.combine(e2)` nessa ordem | os erros mantêm a ordem das validações |

## Exercício 03 — `Applicative`, para `Option` e para `Validated` *(do gabarito)*

| peça | ideia |
| --- | --- |
| `[A] =>> Validated[E, A]` | fixa o tipo de erro e deixa a forma de um buraco que `F[_]` pede |
| `given [E: Semigroup] => Applicative[...]` | condicional, então qualquer `E` com `Semigroup` serve, e nenhum outro |
| `map` a partir de `map2` e `pure` | um applicative é um functor de graça |

## Exercício 04 — `traverse`, escrito uma vez

| peça | ideia |
| --- | --- |
| `map2(acc, f(a))` | a *posição* dos argumentos decide a ordem dos erros; a função só cuida dos valores |
| sem `_.reverse` no fim | o `map` nunca alcança um `Invalid`, então conserta a ordem dos valores mas nunca a dos erros |
| `foldRight` com `map2(f(a), rest)(_ :: _)` | a versão final: sem `reverse` e sem o `:+` quadrático |
| `traverse(forms)(signUp)` | o `traverse` não valida nada sozinho; quem valida é a função que ele aplica |

**Onde travei:** inverti os erros com um laço da esquerda para a direita que
punha cada elemento na frente do acumulador. Depois, o `signUpAll` montava o
`User` direto em vez de chamar o `signUp`, e nada nunca era inválido.
