# Chapter 09 — Tuples as HLists

My notes on what each exercise taught. Reconstructed on 2026-10-13 from the
session of 2026-10-01 (exercises 01 and 04) and, for the others, from the
answer key's scaladoc.

## Exercise 01 — arithmetic on Peano numbers

| piece | idea |
| --- | --- |
| `case (Succ[a], b) => Plus[a, Succ[b]]` | moving one unit from one side to the other keeps the sum: an accumulator |
| `Times`: `(a + 1) · b = b + a · b` | multiplication has no unit to move; recurse with `Plus[b, Times[a, b]]` |
| `Succ[_0]` in a pattern | a lower-case or `_`-prefixed name in a pattern is a *new binder*, not the alias `_0` |

**Stuck on:** my `Times` doubled instead of adding: `Times[a, Plus[b, b]]`
says `(a+1)·b = a·(2b)`, which is false. The way to debug a recursive match
type: write each case as an equation and check it is true. And `Succ[_0]`
matched every successor, so `ToInt` made everything `1`. A good test case is
`Times[_3, _2] =:= _6` — small cases hide the doubling (2·1 = 1+1).

## Exercise 02 — the position of a type in a tuple *(from the answer key)*

| piece | idea |
| --- | --- |
| `case X *: _ => 0` | an upper-case name in the pattern is the type parameter, not a binder |
| `Shift` instead of `+ 1` | `IndexOf[t, X] + 1` turns a `-1` into `0` |

## Exercise 03 — chapter 06's `add`, for tuples of any length *(from the answer key)*

| piece | idea |
| --- | --- |
| an empty rule and a head-and-tail rule | two rules replace every arity; the tail premise is the same rule again |
| every instance and premise as `Aux` | the search can compute `Out` only if each instance's type still says it |

## Exercise 04 — a vector with its length in its type

| piece | idea |
| --- | --- |
| `N + 1`, `N + M`, `N - 1` | types from `compiletime.ops.int`, reduced where `N` is a literal |
| `def head(using N > 0 =:= true)` | the evidence in the signature is resolved at each call, with the concrete `N` |
| a positive proof over `NotGiven` | `NotGiven` fails open: in generic code it accepts; `N > 0 =:= true` fails closed |

**Stuck on:** `summon[N =!= 0]` in the body was resolved once, when `Vec`
compiled, with `N` abstract — and `NotGiven` of an unknown fact always holds.
